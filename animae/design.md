# design.md — Animæ · direction artistique

## Piste verrouillée : « C — spectre »
- **Near-black** partout. Base ~ `#060708`.
- **Accent spectral tiré du visuel lui-même** : magenta `#c34ea0` au centre, plage **indigo → magenta → ambre** (`#4b3aa8 → #c34ea0 → #e8b86c`). Seul l'élément actif s'allume ; le reste reste sombre.
- **Typo** : mono (**IBM Plex Mono** / DM Mono) pour le HUD / l'instrument · grotesque (**Instrument Sans**) pour le wordmark. Pas de serif littéraire.
- **Retenue** : hairlines fines, glass discret, sentence case, zéro ornement.
- L'identité se tient **à côté** de l'instrument. Le canvas nu = le floor.

## Interdits DA
- ❌ médiéval / parchemin / héraldique / serif littéraire / gold-violet décoratif sur l'UI.
- ❌ générique-IA (purple gradient sur blanc, Inter par défaut, layouts cookie-cutter).
- ❌ post-FX 2D plat façon **Synaptic Mirror** (anti-référence).
- ❌ relief « terrain rocheux » générique (l'essai raté, cf. `apercu_defauts.png`).

## Gestes (langage visuel)
toucher = beauté · maintenir = intensité · taper = changer d'état. Pictos > texte. Anglais en filet seulement.

## Modes (public)
- **Simple** — canvas nu, gestes, un bouton « surprise » (chaos). Zéro slider.
- **Public** — 3-4 grosses macros + source (image / webcam).
- **VJ** — rack complet : params, pile d'effets, graine / chaos, entrées, capture, perf.
