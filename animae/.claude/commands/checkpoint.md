# /checkpoint — git add . + commit rapide

Stage tout et commite avec le message passé en argument.

## Instructions

1. Lance `git status --short` pour montrer ce qui va être commité.
2. Lance `git add .`
3. Commite avec exactement ce message : `$ARGUMENTS`
   — ne le reformule pas, ne le complète pas, utilise-le tel quel.
4. Confirme en une ligne : sha court + liste des fichiers commités.
