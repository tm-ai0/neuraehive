# NeuraeHive

NeuraeHive, c'est l'atelier d'Æthereact : des instruments audiovisuels et des systèmes génératifs, organiques, bioluminescents, cybernétiques.
Ce dépôt est un carnet d'expérimentations : des essais faits pour apprendre et pour le plaisir de les partager, pas des produits finis. Certains tiennent debout, d'autres sont restés en chemin, et c'est très bien comme ça.

Le dépôt est le site [nh.thomasmaury.fr](https://nh.thomasmaury.fr) lui-même : la page d'accueil, puis un dossier par projet, comme en ligne. Quand un projet se compile (cinerae, pulse), les fichiers servis sont à la racine de son dossier et le code source dans `source/`. Les brouillons et versions intermédiaires sont rangés dans des dossiers `archive/`.

# NeuraeHive (English)

NeuraeHive is Æthereact's workshop: audiovisual instruments and generative systems, organic, bioluminescent, cybernetic.
This repository is a notebook of experiments: things made to learn and for the pleasure of sharing them, not finished products. Some stand on their own, others stopped along the way, and that is fine.

The repository is the [nh.thomasmaury.fr](https://nh.thomasmaury.fr) site itself: the home page, then one folder per project, as online. When a project has a build step (cinerae, pulse), the served files sit at the root of its folder and the source code lives in `source/`. Drafts and intermediate versions are kept in `archive/` folders.
